Request Desktop Site

English · Русский

As in iOS 9: in Safari, tap Share and choose Request Desktop Site — the page reloads in its desktop version. Request Mobile Site in the same menu brings the usual one back.

Mobile addresses like m.site.com are replaced with the regular ones automatically.

Как в iOS 9: в Safari нажмите «Поделиться» и выберите «Полная версия» — страница перезагрузится в версии для компьютера. «Мобильная версия» в том же меню вернёт обычную.

Мобильные адреса вида m.site.ru автоматически заменяются на обычные.
